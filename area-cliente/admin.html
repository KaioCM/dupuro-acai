    Novo produto

    Nome, preço e uma foto opcional
    Copo e self-service são vendidos só no balcão (caixa) — não aparecem para o revendedor.
    Define os códigos que saem no cupom fiscal (NFC-e). Escolha um perfil pronto — os códigos aparecem abaixo. Use Personalizado só se precisar de códigos diferentes.
    O cliente escolhe até N acompanhamentos da lista de gratuitos sem custo; cada um a mais soma o preço do extra. Acompanhamentos pagos (ex: Nutella) cobram sempre o preço próprio.
    Marque os dois para vender o mesmo produto nos dois preços — eles dividem o mesmo estoque.
    Volume que cada unidade soma no pedido (caixa 10 L = 10; pote 500 ml = 0,5). Deixe 0 para itens que não são açaí/creme (granola, refrigerante). Serve para dispensar o pedido mínimo em pedidos grandes.
    Cada sabor tem seu próprio estoque. Sabor com 0 não pode ser pedido pelo revendedor.

    Regra de pedido mínimo

    Pedido grande dispensa o pedido mínimo de todos os itens — o cliente que puxa volume pode completar com 1 unidade de qualquer produto.
    Hoje: 50 L = 5 caixas de 10 L, ou 10 caixas de 5 L, ou qualquer mistura. O volume de cada produto é o campo “Litros por unidade” do cadastro de cada produto.
